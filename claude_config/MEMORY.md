# PROJECT MEMORY: THE POLYMATH.SYS GENESIS

This document contains the deep context, history, and philosophical "Vision" of **Polymath.Sys**. Use it to align every design and architectural decision with the core mission.

---

## **1. PROJECT VISION: V4.0 (THE AUTOMATION AGE)**
Polymath.Sys began as a static, archival set of HTML files for deep learning in **AI**, **Mathematics**, and **Quantum Computing**. 

**Version 4.0** (The current phase) transforms the portal into a **Dynamic Intelligence Core**. It is no longer just a curriculum; it is a real-time research sensor that:
- Monitors ArXiv for breakthroughs.
- Automates the 48-month learning roadmap.
- Generates high-end research PDFs.
- Provides a centralized "Bento Dashboard" for elite researchers.

---

## **2. THE 48-MONTH CURRICULUM (CORE DNA)**
The curriculum is divided into three distinct phases for deep-growth mastery:

### **Phase 1: Learning & Solidification (Months 0-12)**
- **Focus**: Linear Algebra, Calculus, Statistics, and "Karpathy-style" Neural Networks.
- **Goal**: Build from scratch. No high-level wrappers.

### **Phase 2: Deep Research & Architecture (Months 12-36)**
- **Focus**: Transformers, LLM Training (Pre-training, SFT, RLHF), and RAG pipelines.
- **Goal**: Understand State-of-the-Art (SOTA) architectures and implement them.

### **Phase 3: Frontier Growth & Quantum (Months 36-48+)**
- **Focus**: Quantum Machine Learning (QML), Frontier Research, and Industry Alignment.
- **Goal**: Research and contribute to the edge of human knowledge.

---

## **3. DESIGN PHILOSOPHY: BRUTALIST PREMIUM**
- **Inspiration**: Industrial engineering manuals, Obsidian-style notes, and high-end command-line terminals.
- **Psychology**: Reduce visual noise. Increase information signal. Use "Dark Mode" as the only mode to reduce eye-strain during 12+ hour research blocks.
- **Interaction**: Hovering should feel like "unlocking" metadata. Transitions should be instantaneous but smooth.

---

## **4. THE AUTOMATION LAYER HISTORY**
The project already contains operational Python scripts for:
- **`generator.py`**: A PDF engine that creates study-guides from Markdown files.
- **`updater.py`**: A logic-bridge that injects icons and links into HTML files.

**Migration Goal**: These scripts must now be integrated as **Pre-build hooks** or **GitHub Action triggers** that feed into the Astro Content Collections.
